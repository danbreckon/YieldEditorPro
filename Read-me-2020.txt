Yield Editor Pro — a Precision Planting .2020 file

A shapefile, a zip of a shapefile, or a text file opens in the page.
That page is the part anyone can take.

A .2020 file does not open in the page alone. Reading it needs the
Precision Planting 20|20 ADAPT plugin. That plugin is theirs. It is not
in this repo, and it is not part of the gift. This project does not
offer the plugin, or a zip that contains it, for download.

Do not copy the plugin onto a stick, attach it to a release, or hand it
to a grower as part of this page. A wider distribution needs written
leave from Precision Planting. Until that leave exists, the plugin stays
with the person who licensed it.

If a reader licensed from Precision Planting is already on that computer,
the page can send a dropped harvest .2020 to it. The page cannot install
the reader. Planting and sprayer .2020 files are not read yet.

A raw John Deere display card is not read. The John Deere ADAPT plugin
has to be licensed before that drop can work. Until then, use the harvest
shapefile that display writes.
